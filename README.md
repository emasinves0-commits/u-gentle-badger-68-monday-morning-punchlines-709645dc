A one-line joke program for the make.fun bounty "Monday Morning Punchlines". It validates a single line of text and writes it to `/output/entry.txt`.

> Monday's alarm doesn't wake me — it invoices the dream for unauthorized weekend occupancy.

Run it with `node main.ts`.
